# To-Do List Android App

A simple To-Do List Android application developed using Java, XML, and SQLite.

## Features

- Add new tasks
- Set task priority
- Mark tasks as completed
- Edit tasks
- Delete tasks
- Store tasks using SQLite
- Tasks remain saved after closing the app

## Technologies Used

- Java
- XML
- Android Studio
- SQLite
- ListView
- BaseAdapter

## CRUD Operations

- Create - Add new tasks
- Read - Display saved tasks
- Update - Edit and complete tasks
- Delete - Remove tasks
